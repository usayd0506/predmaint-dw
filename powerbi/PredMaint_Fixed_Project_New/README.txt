HOW TO OPEN (read this first)
1. Unzip the WHOLE zip. Keep these three items together in the same folder:
     Usyad Power Bi report.pbip
     Usyad Power Bi report.Report   (folder)
     Usyad Power Bi report.SemanticModel   (folder)
   The .pbip file is only a shortcut. If the two folders are missing or renamed you get
   "Required artifact is missing ... definition.pbir".
2. Power BI Desktop > File > Options > Preview features > tick "Power BI Project (.pbip) save option". Restart.
3. File > Open report > Browse > select "Usyad Power Bi report.pbip".
4. A project does NOT contain data. Put the CSV files in a folder, then Home > Transform data >
   Data source settings > Change source (or edit the file path in each query) and click Refresh.
EASIER: send a single .pbix file instead (File > Save as > .pbix). It contains the data.
